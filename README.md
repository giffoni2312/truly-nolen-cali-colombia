# Truly Nolen · Cali, Colombia (borrador)

Sitio de control de plagas de Truly Nolen para **Cali, Colombia**. Proyecto aparte: no se mezcla con ningún otro país.

**Ver en línea:** https://giffoni2312.github.io/truly-nolen-cali-colombia/oficinas/cali/

## Comandos
- `node build.mjs` → arma las 16 páginas en `site/` (necesita la copia local de referencia, que no se sube)
- `node check.mjs` → revisa orden de secciones, menú, pie, enlaces y restos de otros países
- `node serve.mjs` → vista local en http://localhost:8090/oficinas/cali/
- `node publicar.mjs` → copia `site/` a `docs/` (lo que publica GitHub Pages)

## Dónde se edita
- `src/pages.mjs` → textos, plagas y fuentes de cada página
- `src/helpers.mjs` → bloques de cada sección
- `assets/` → imágenes de Cali
- `investigacion-cali.md` → datos con su fuente
